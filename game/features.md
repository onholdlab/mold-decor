# 功能地圖（B2 最小可玩版本）

`互動｜怎麼觸發｜預期畫面或狀態`

- 開場｜打開 `game/index.html`｜層板上有一塊吐司，青黴已經長了一些菌絲和一支掃帚狀孢子柄；第 1 天；提示「點牆面放米、麵包、水滴或乾燥劑」
- 選工具｜點下方「麵包／米／橘子／木片／水滴／乾燥劑／孢子」chip｜被選的 chip 變深色；選「孢子」時多一排已發現種類可選
- 放食物｜選「麵包／米／橘子／木片」後點牆面｜點的位置出現該食物；條件對時，幾秒到幾十秒後會有孢子自己落下來長出菌落；同樣條件下可能有幾種候選，誰先到有運氣成分
- 潮濕牆面｜滴水後不放食物｜條件對時枝孢會直接長在牆上（牆角接縫上方也有一個天然潮濕點）
- 菌絲找路｜在現有菌落附近放食物｜菌絲尖端轉向食物長過去；第一次碰到新食物時提示「菌絲自己找到你放的…」，圖鑑解鎖「菌絲找路」
- 滴水｜選「水滴」後點牆面｜出現淡藍水漬；附近變潮，菌絲能長過原本太乾的地方
- 乾燥劑｜選「乾燥劑」後點牆面｜出現白色小包和淡白光暈；菌絲碰到會轉彎或停下
- 放孢子｜選已發現種類的孢子後點牆面｜出現一個小色點；條件夠就開始長，太乾或太冷時提示會先休眠／長很慢
- 濕度｜點「乾燥／普通／潮濕」｜左上狀態列更新；乾燥時大部分菌絲停下
- 溫度｜點「涼／常溫／暖」｜左上狀態列更新；麴菌、紅麴在暖時長得快，青黴在涼和常溫時長得好
- 發現新種類（9 種）｜條件符合時自然長出（例：米＋潮濕＋暖 → 麴菌；米＋普通＋暖 → 紅麴；木片 → 木黴；橘子＋涼＋潮濕 → 灰黴）｜提示「發現新種類」，孢子列多一個該種，圖鑑計數 +1
- 演替｜新鮮麵包放在潮濕處｜根黴或毛黴先長、長出孢子囊兩天後退場，之後換別種長；圖鑑解鎖「演替」
- 休眠｜把孢子放在太乾的地方，之後再滴水或調潮｜孢子先不動，變潮後開始長；圖鑑解鎖「休眠的孢子」
- 漸進提示｜很久沒有新發現｜未解鎖物種卡的提示每 2 天多一條（食物 → 溫度 → 濕度）
- 拮抗線｜讓兩種黴菌長到碰面｜交界處留下一條空白；圖鑑解鎖「拮抗線」
- 猜想卡：電訊號｜菌絲網總面積夠大｜解鎖紫底「猜想」卡；之後菌絲上會有紫色光點沿著菌絲跑（卡片上寫明這是把電訊號畫出來，現實中肉眼看不到）
- 猜想卡：菌絲網分享養分｜一個菌落連到 3 塊食物｜解鎖第二張猜想卡；之後連到多塊食物的菌落上有綠色光點流動
- 成熟｜菌落吃到足夠食物｜長出孢子構造：掃帚狀（青黴、枝孢、灰黴）、放射頭（麴菌、黑麴菌）、菌落（紅麴、木黴）、孢子囊（根黴有假根、毛黴）；每個菌落最多 6 個
- 圖鑑｜點「圖鑑 n/15」｜底部面板分「黴菌／現象／猜想」三段列出 15 張卡；未解鎖顯示「？？？」和提示；已解鎖物種有發現條件與「看科學圖版」連結
- 速度｜點「速度 ×1」｜切換 ×1／×4
- 重來｜點「重來」兩次（3 秒內）｜場景重置回開場；圖鑑保留（localStorage）
